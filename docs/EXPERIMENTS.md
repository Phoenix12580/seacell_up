# 上皮/肿瘤细胞处理实验报告（方案 3 + 方案 4）

> **v2 更新（2026-08-18）**：用户决策——粗 MC(方案 3) 否决（分辨率损失），
> CNV 空间改**按样本分治**（每样本自己的 k_dim/γ/K，克隆结构病人特异）。
> 见文末"实验 A-v2"。核心结果：**上皮 unresolved 27.0% → 13.4%，
> 表达空间噪音细胞找回率 21.3% → 79.7%，方差比 0.343 → 0.192，全细容量 [20,35]**。

> 数据：Zhao 222K 中 90,626 个上皮细胞（表达空间基线 unresolved 率 27.0%，24,509 个）
> CNV 推断：infercnvpy 0.6.1（免疫 20K 参考，Gencode v44 坐标，16,338 基因）
> 脚本：`scripts/cnv_infer_epithelial.py` + `scripts/exp_epithelial_experiments.py`

## 背景

全量流水线中被标噪音的 24,535 个细胞 99.9% 是 Epithelia（富集 2.99 倍）。
cnv_score 分布显示约 15-20% 上皮有明显恶性信号（P90=0.0143，P99=0.0229，
中位 0.0088 与免疫参考 0.0078 接近）——Benign/Tumor 混合样本的预期结构。

## 实验 A（方案 4）：上皮在 CNV 空间建 Metacell [20,35]

| 指标 | 值 |
|---|---|
| Metacells | 2,590（容量严格 [21,35]） |
| 单轮通过率 | **44.7%**（表达空间 stage1 单轮仅 22.1%，翻倍） |
| MC 内 cnv_score 方差比(组内/组间) | **0.343**（MC 与 CNV 克隆结构高度对齐） |
| 表达空间 unresolved 的找回率 | 5,221/24,509 = **21.3%** |

解读：表达谱连续但 CNV 克隆清晰的细胞（恶性克隆）在 CNV 空间顺利成团——
这正是方案 4 的目标人群。CNV 空间 MC 同时天然携带克隆注释。

## 实验 B（方案 3）：unresolved 细胞建粗容量 super-MC [80,160]

| 指标 | 值 |
|---|---|
| 输入 | 24,535 细胞（99.9% 上皮） |
| super-MC | 162 个（容量严格 [80,160]），γ 自适应=147.6 |
| 单轮通过率 | **47.5%** |
| ct.sub 纯度（中位） | **1.000**（粗 MC 内类型完全一致） |
| cnv_score 方差比 | 0.777（不如 CNV 空间的 0.343，符合预期） |

解读：**"连续谱而非噪音"假设成立**——近一半 unresolved 细胞在放宽分辨率后
立即形成类型纯净、结构良好的 Metacell。它们不是垃圾，是分辨率错配。

## 结论与落地建议

1. 粗 MC 输出被否决（分辨率损失）；其实验价值降级为"证明 unresolved 细胞有结构"。
2. **方案 4 作为肿瘤样本专项路径**：上皮走 "CNV 空间建 MC"（infercnv 前置），
   表达空间与 CNV 空间结果互补对照。
3. **两者正交互补**：方案 3 证明连续谱可结构化，方案 4 回收恶性克隆。
4. 工程注意：90K 行 fit_embedding 的 sklearn MiniBatchNMF 全量收敛验证是
   当时最大时间成本（~30 分钟）；可改为子样本拟合 H + 全量 transform。

## 实验 A-v2（最终采纳）：CNV 空间 + 按样本分治 + 细容量 [20,35]

用户对 v1 的两点修正：(1) 粗 MC 输出否决（分辨率损失）；(2) NMF/Metacell
构建应按样本分治——CNV 克隆结构是病人特异的，跨病人混合建块选出的
k_dim/γ 是"混合体最优"而非"任何克隆结构的最优"。

流程：76 个样本块（≥40 细胞，每块独立 auto_select k_dim + γ 搜索 + GNMF，
容量严格 [20,35]）→ 全局 mean 线单轮筛选 → 失败者(46,549)跨样本 rescue
1 轮 → rescue 失败者在自身分布内 median 线分层放行 → 剩余 is_noise。
脚本：`scripts/exp_cnv_bysample.py`，总耗时 5,726s（95 分钟）。

| 指标 | v1 混合版 | **v2 按样本分治** | 表达空间基线 |
|---|---|---|---|
| 单轮通过率 | 44.7% | **48.5%** | 22.1% |
| MC 数 | 2,590 | 2,791 | — |
| 每样本自适应参数 | 无（全局） | k_dim 10-85, γ 26.7-170, K 各异 | ✓（本来就有） |
| cnv_score 组内/组间方差比 | 0.343 | **0.192** | — |
| ct.sub 纯度 (median/mean) | — | **1.000 / 0.999** | — |
| 表达空间噪音找回率 | 21.3% | **79.7% (19,530/24,509)** | — |
| 最终上皮 unresolved | — | **13.4%** | 27.0% |
| Metacell 容量 | [21,35] | **[20,35] 全程** | [20,35] |

rescue 轮细节：池 46,549 → K=1,330，mean 线通过 47.7%；分层（失败者内
median）累计放行 73.8%。分层回收是"纯评分操作"——放行的 MC 保持
20-35 细胞不变，只在失败者分布内重新比较，不产生粗 MC。

### 结论（修订）

1. **上皮路径定稿**：CNV 空间（infercnvpy，免疫参考）+ 按样本分治 +
   细容量 [20,35] + 失败者 rescue 1 轮 + 分层放行。上皮 unresolved
   27.0% → 13.4%，且 79.7% 的表达空间"噪音"细胞以细 MC 形式找回。
2. **两个判断均被实验证实**：按样本分治优于混合建块（方差比
   0.34→0.19、单轮率 44.7%→48.5%）；细容量+分层回收优于粗 MC
   （同等找回率下无分辨率损失）。
3. 剩余 13.4%（约 1.2 万）才是接近真噪音的细胞（低质量/极罕见状态）。
4. 工程优化空间：76 块各跑 16,338 基因全维 NMF 是主要成本；CNV 矩阵
   可预先做方差筛选再进流水线（见 v3）。

## 实验 A-v3（TOP3000 固化版，用户决策 2026-08-18）

用户决策：NMF 特征用方差 top3000（16,338 全维是分治阶段主要成本）。
已固化为 `seacell_up/cnv_branch.py`（`run_cnv_branch` + `CNVBranchConfig`），
run_pipeline.py 提供 `--cnv-input` 可选分支集成。

| 指标 | v2 全维 16,338 | **v3 top3000** |
|---|---|---|
| 总耗时 | 95 min | **61 min**（分治并行段 40→21 min） |
| 单轮通过率 | 48.5% | 42.0%* |
| 单轮 MC cnv_score 方差比 | 0.192 | **0.183** |
| 单轮 MC ct.sub 纯度 (median) | 1.000 | **1.000** |
| 表达空间噪音找回率 | 79.7% | **83.7%** |
| 最终上皮 unresolved | 13.4% | 15.5%* |

\* 单轮率/unresolved 略变的机制：top3000 后 Score 分布整体压低
（mean 线 0.479→0.322），单轮过线比例略降；但通过的 MC 与克隆结构
对齐度反而更高（方差比 0.183），最终找回率与纯度均优于全维。

结论：**top3000 采纳**——质量持平或更优，速度 +36%（NMF 特征数
线性收益；rescue 池 GNMF 不是 NMF 瓶颈，故总加速 < 分治段加速）。

## hvg_mode 对比实验（2026-08-24，用户提议可选项）

用户提议：HVG 应支持"各样本分别找"，让用户自选哪种效果好。实现为
`hvg_mode: "global" | "per_sample"`。per_sample 语义（用户第二次澄清）=
第一轮各样本独立选 HVG，回收轮用**剩余细胞合并选**（剩余细胞的"全局"
HVG）——由 HVG 选择放在 `_process_block` 块内自然实现。

关键事实：MC 伪体始终在**全基因**上聚合（HVG 只影响 NMF 构建输入），
因此两种模式的伪体输出可直接对比，跨样本可比性不受构建期 HVG 影响
（当初评估 P4 选择全局 HVG 的主要理由之一由此不再成立）。

数据：Zhao 抽 10 样本（57,641 细胞；Immune 45.7K / Epithelia 6.8K /
Stromal 5.1K），同参数各跑一遍。脚本 `scripts/exp_hvg_mode.py`。

| 指标 | global | per_sample |
|---|---|---|
| ct.main median / mean | 1.000 / 0.9795 | 1.000 / 0.9775 |
| ct.main ≥0.95 | 91.3% | 90.6% |
| ct.sub median / mean | 1.000 / 0.9534 | 1.000 / 0.9486 |
| ct.sub ≥0.95 | **81.8%** | 78.8% |
| 噪音率 | **5.9%** | 10.4% |
| Metacells | 1,645 | 1,545 |
| 耗时 | 2,003s | 2,108s |

结论：这批免疫为主的子集上 **global 略优**。per_sample 噪音率翻倍的
候选机制：(1) 不同特征空间的质量分过同一条全局 mean 线，跨块可比性下降；
(2) 小样本 HVG 的方差估计更噪。上皮/肿瘤为主（样本特异克隆基因丰富）
的场景差异可能反转——两种模式都保留，建议对自己的数据跑
`exp_hvg_mode.py` 对比后选择。默认值保持 global（有本实验证据支持）。
